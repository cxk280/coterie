# coterie (JavaScript / TypeScript)

The Node runtime for [Coterie](https://coterie.dev) — a LangGraph orchestrator for heterogeneous coding agents.

```bash
npm install coterie
npx coterie run "refactor src/auth.ts to remove the legacy middleware" \
  --config examples/fanout_with_judge.coterie.yaml
```

See the [top-level README](../../README.md) for architecture, design, and the Python sibling package.
